What works now

  • Strict validation API, tests and locked builds.
  • Automatic Jenkins CI and security-gated image archival.
  • Local application, dashboard, alert and JSON-log demonstrations.
  • Actual local build notifications with source revision.

What we must still build and prove

  • Approved cloud environment and registry-to-cluster delivery.
  • Two Ready pods, successful rollout and pod recreation.
  • Cloud monitoring/log collection and rollback verification.
  • Controlled exposure, costs, evaluator access and teardown.

How to read this map

The first lane is delivery. The second is the target request path. The third is telemetry and operator response—not another application dependency chain.

No frontend, database, actual payment processing or mandatory AI model is introduced. Cloud service choices remain deliberately unspecified.
